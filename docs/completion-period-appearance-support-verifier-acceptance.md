The final independent full-comparison tests explicitly forbid old C-report
reads, independently derive each expected command, and run all forty/eleven
actual commands. Both baselines pass. For each component, seven malformed
parsed cases reject before the first C call: hidden child tags, renamed child

and 39 support source-domain refusals; eighty appearance and thirty-three
support native output files remain byte-identical. Earlier fresh runs of the
unchanged protocol/domain tests passed appearance 14/9 and support 17/9.

establish the typed input preconditions by construction or reject unsupported
state; this approval does not turn the raw probe into a general machine-state
implementation. The original counterexamples and failed reports are retained.

The original behavior comments remain correct: appearance's canonical B630

the period parent's separate A6/fraction/readiness quirks. DBR was not captured
